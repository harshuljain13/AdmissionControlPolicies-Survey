% Libertine, loaded as OpenType through fontspec. Two reasons.
%
% Typography: this is the face acmart uses for the CSUR build, so the
% preprint and the journal version read alike instead of the preprint
% looking like a different paper set in Computer Modern.
%
% Extraction: the T1-encoded Type1 route stores fi, fl and ffi as single
% glyphs with no Unicode mapping, so pdftotext, Google Scholar and screen
% readers read "classi" for "classification". The OpenType cut is
% Identity-H encoded and maps back correctly, which means ligatures stay
% on and the text is still searchable. Filenames rather than family names
% because fontspec cannot resolve "Linux Libertine O" in this bundle.
\usepackage{fontspec}
\setmainfont{LinLibertine_R.otf}[
  BoldFont=LinLibertine_RB.otf,
  ItalicFont=LinLibertine_RI.otf,
